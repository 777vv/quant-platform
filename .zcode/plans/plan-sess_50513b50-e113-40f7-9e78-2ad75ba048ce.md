## 创建内容（约 70 个文件）
1. **根**：父 `pom.xml`（统一版本/模块管理）、`.gitignore`、`.env.example`、`Dockerfile`（多阶段）、`docker-compose.yml`、简版 `README.md`
2. **quant-common**（可拔插，零业务依赖）：`R<T>`/`PageResult`/`ResultCode`、`BizException` + 全局异常处理器、`TraceIdFilter`/`TraceIdGenerator`/`MdcTaskDecorator`、`JacksonConfig`、工具类（日期/金额精度/JSON/字符串）、`AsyncConfig`（线程池+MDC透传）、`RedissonConfig` + `LockUtils`、`logback` 相关
3. **quant-system**：`SysUser` 实体/Mapper、登录/登出/me/改密/资料接口、`SaTokenConfig` 拦截配置、防爆破锁定、`DataInitializer`（启动时无用户则创建 admin，密码来自配置项，避免手写 bcrypt 哈希）
4. **quant-fund / quant-strategy / quant-ai**：仅模块 POM 占位（M2+ 填充）
5. **quant-web**：启动类、`application{,-dev,-prod}.yml`、`logback-spring.xml`（app/error/eastmoney 三文件、滚动、异步、profile 差异）、`schema.sql`（15 张表，全部 IF NOT EXISTS 幂等）、SPA 路由回退 Controller（保护 /api 前缀）、frontend-maven-plugin 集成（默认 `skipFrontend=true`，全量构建用 `-DskipFrontend=false`）
6. **web/ 前端**（手写脚手架，不用交互式向导）：Vue3+TS+Vite+ElementPlus+Pinia+ECharts+vue-router+axios；axios 封装（satoken 头、traceId 错误提示、401 跳转）、路由守卫、主布局（侧边栏+顶栏）、登录页、仪表盘/基金池/导入/用户中心占位页、ESLint(flat)+Prettier
7. **M1-10 规范工具**：`maven-pmd-plugin` + PMD 6.55.0 + `p3c-pmd 2.1.1`（p3c 仅兼容 PMD6，必须钉版本），绑 verify 阶段阻断 Blocker/Critical

## 关键决策（均已按文档/已确认口径）
- BCrypt 用 SaToken 自带 `cn.dev33.satoken.secure.BCrypt`，不引入 spring-security
- Docker 内：node 阶段构建 dist → 拷入 static → `mvn package -DskipFrontend=true`（避免容器内重复装 node）
- schema.sql 用 `spring.sql.init.mode=always` + 全 IF NOT EXISTS，幂等启动
